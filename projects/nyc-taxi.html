NYC Taxi Fleet Positioning

A fixed fleet of 13,000 yellow cabs has to be pre-positioned across 263 zones. A cab in the wrong place is idle cost; a missing cab is a lost fare.

A newsvendor allocation that sets how many cabs to stage in each zone before a shift, using the fact that a missed fare costs more than an idle cab.

The problem

The medallion fleet cannot grow overnight. The decision is where cabs start each time window. Missing a trip costs about $17. Leaving a cab idle costs about $12. A forecast that only minimizes error ignores that imbalance.

Approach

  • Aggregated yellow-cab demand by zone, time bucket, day of week, and month.
  • Set each zone’s service level from the cost ratio: critical fractile = missed-fare cost ÷ (missed fare + idle cost).
  • Allocated the 13,000-cab budget so high-fare zones, such as airports and Midtown, hold more slack than quiet zones.

Result

On the modeled slots, repositioning lifts revenue from about $188K to about $426K per slot. Annualized, that is about $12.4M. That figure is a model projection on historical demand, not a booked P&L result.

What this leaves open

The engine recommends a starting position. It does not yet replan when weather, a street closure, or a manager’s instruction changes the costs. The public page is the decision tool. The GitHub README is the full writeup. The trip aggregate and the allocation code are not in that repository.
