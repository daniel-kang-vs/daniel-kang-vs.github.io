Seed Planning Dashboard

Seed production planners were reading wide, messy yearly files to decide what to grow and what to hold. The public demo uses synthetic data with the same shape as the partner file.

An analytics pipeline and dashboard for Hubner Seed, built with the Purdue Data Mine, covering descriptive views and a demand-forecast comparison.

The problem

Production history arrived as messy, wide spreadsheets, one shape per year. Planners needed one view of which lines were consistent, and a forecast they could compare with a simple baseline before changing inventory.

Approach

  • Built an ETL step that normalizes multi-year files into one analysis table.
  • Shipped descriptive views: mix, consistency, and line-level trends.
  • Compared regression and machine-learning forecasts on R² and RMSE.
  • Published a GitHub Pages demo on synthetic data so the workflow is visible without the partner’s file.

Result

The pipeline turns a new upload into a cleaned table and a dashboard. Planners can see mix and trend before they trust a forecast, and the model page shows which method actually fits the series.

Inspect the implementation

The Python pipeline finds header rows in inconsistent exports, normalizes columns, reshapes company quantities into rows, and combines yearly files. The Dash application provides descriptive views and an upload workflow.

What this leaves open
