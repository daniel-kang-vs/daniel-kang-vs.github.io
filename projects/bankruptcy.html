Bankruptcy Risk Scoring

Predict bankruptcy from 64 financial ratios when the failing firms are a small minority, so accuracy is a useless score.

An XGBoost ranker with winsorized outliers and KNN imputation, scored on ROC-AUC inside stratified cross-validation.

AUC 0.9073rd of 53 teams64 ratios5-fold CV

Live demo →GitHub ↗

The problem

Credit teams need a ranking of firms that may fail, not a model that looks accurate by predicting “solvent” every time. The training set is about 10,000 firms and 64 ratios, with missing values and extreme outliers.

Approach

  • Winsorized each ratio at the 0.5th and 99.5th percentiles so a few broken values did not dominate the trees.
  • Imputed missing ratios with 5-nearest neighbors so relationships between ratios stayed intact.
  • Trained XGBoost with L1 and L2 penalties and judged it by mean ROC-AUC on 5 stratified folds.

Result

Mean cross-validated AUC was 0.907, with fold scores from 0.875 to 0.936. The submission placed 3rd of 53 teams in the Purdue MGMT 571 competition.

What this leaves open

AUC ranks firms. It does not set the cutoff a lender should use. A production version would pick that threshold from the cost of a missed bankruptcy versus a false alarm, and would fit imputation inside each fold so the score cannot leak.
