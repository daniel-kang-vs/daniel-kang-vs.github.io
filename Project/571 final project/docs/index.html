The Problem

Rare events in messy financial data

Only 4.3% of companies in the training set went bankrupt — a heavily imbalanced classification problem. On top of that, many financial ratios have missing values and extreme outliers that can distort tree-based models if left untreated.

Class Distribution

9,573 survived vs. 427 bankrupt. The model must learn from very few positive examples.

Missing Values (Top Features)

Up to 34% missing on some attributes. Simple mean-fill would break correlations between ratios.

Pipeline Impact

Preprocessing mattered as much as model choice

Winsorization clips extreme ratios to the 0.5th–99.5th percentile. KNN imputation (k=5) fills gaps using similar companies’ profiles. Only then does XGBoost see clean, comparable features.

AUC by Preprocessing Step

Each step adds ~1–2 points of AUC. Raw data alone scored 0.872; the full pipeline reached 0.907.

End-to-End Flow

5-fold stratified CV ensures each fold keeps the 4.3% bankrupt rate.

Results

Consistent across folds and the competition leaderboard

AUC held between 0.875 and 0.936 across all five folds. The approach ranked 3rd of 53 teams — careful preprocessing plus a well-tuned XGBoost outperformed many larger ensemble stacks.
