Decision Support Case Study

Ranking at the Cut Line

When capacity is fixed and most candidates miss the cut, ranking quality is not enough — the selection boundary itself must be calibrated. This project turns multi-signal team data into a prioritization system under uncertainty: who clears a hard slot constraint, and in what order.

See Impact Source Code

01 — Business Context

Fixed slots. Uneven odds. Costly misses.

The domain is NCAA tournament selection, but the decision problem is familiar in business: prioritize a long list when only a fixed number of slots exist, signals conflict, and false positives burn scarce capacity.

Hard capacity constraint

Exactly 68 bids. Over-selecting is as wrong as under-selecting — the same failure mode as over-promoting SKUs, leads, or vendors past a budgeted quota.

Severe class imbalance

Only ~26% of historical teams earn a bid. Default thresholds inflate the selected set; the model must find the boundary, not just rank the middle of the pack.

Two-stage decision

First: binary clearance (in / out). Second: ordered priority (seed 1–68). Same pattern as shortlist → tier assignment in hiring, lending, or inventory allocation.

Transferable framing: multi-signal ranking and threshold calibration for any prioritization problem where leadership must defend a cut line under uncertainty.

03 — Methodology

Stacked ensemble + calibrated cut line

Eight base learners feed a meta-model trained with 10-fold cross-validation. Selection scores are then threshold-calibrated on the precision–recall curve so the predicted set size lands near the 68-slot business constraint — not at a naive 0.5 probability cutoff.

Layer 1

Base models

Diverse learners capture different non-linearities and ranking biases across the feature space.

Layer 2

Meta-learner

Stacking blends base probabilities with out-of-fold training to reduce single-model overconfidence.

Constraint

Threshold at 0.653

PR-curve calibration replaces the default 0.5 cutoff, pulling selected volume from ~76 toward ~68 slots.

Stage 2

Seed ranking

Conditional on selection, a second model assigns ordered priority (seed) across the cleared set.
